DealScope — a real Black Friday deal finder: 96 deals at 4 stores, each price read on 27 Nov 2026 from a deals source that names the store, with an honest "is it really a deal" signal on every card (19 new lows), a ranked Top 5 strip, cross-store price comparison for 13 products, and search + filters by category, store and discount that work. Static files only, no network requests at runtime; works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
